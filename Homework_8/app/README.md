# MLE_course_project_1: Приложение по анализу отзывов в сфере HoReCa

Сервис для автоматического анализа отзывов, определения эмоций, причин, повлиявших на впечатление от посещения, создание аналитических дашбордов по отзывам, автоматизация ответов и отправка оповещений с результатами анализа

## Функционал:

* ### Авторизация/регистрация:

Со стартовой страницы пользователь переходит на форму, где вводит логин и пароль.

* ### Личный кабинет:

Просмотр баланса, пополнение баланса.

* ### Работа с моделью:

На странице личного кабинета пользватель загружает отзыв и получает оценку по шкале 1-5. 

* ### Просмотр истории предсказаний и транзакций:

Реализована возможность перейти на страницы с историей предсказаний и тарнзакций.

* ### Log Out:

Пользователь может разлогиниться.

* ### ML-модель:

Rubert, обученный по отзывам в сфере HoReca: 
https://huggingface.co/sharlotik/rubert_base_horeca_reviews_rating/tree/main 

Macro F1-score: 0.61, weighted F1-score: 0.85.
