# MLE_course_project: Автоматизация анализа отзывов в сфере HoReCa с помощью методов ИИ

Сервис для автоматического анализа тональности, выявления причин оценки, создания аналитических дашбордов и генерации эмпатичных ответов на отзывы


* ## Модель по оценке рейтинга на основании тональности отзывов

* ### Источник данных:

Yandex Geo Reviews Dataset 2023 (Kaggle):

https://www.kaggle.com/datasets/kyakovlev/yandex-geo-reviews-dataset-2023

140 тыс. записей

Дисбаланс классов в сторону 5: 77.4%

* ### Train/Test split:

Групповое стратифицированное разделение по организациям (GroupStratifiedKFold):  
80% (train +valid) / 20% (test) 

* ### ML-модель:

Rubert, дообученный по отзывам на рассматриваемом датасете: 
https://huggingface.co/sharlotik/rubert_base_horeca_reviews_rating/tree/main 

Macro F1-score: 0.62, weighted F1-score: 0.86.


## Функционал приложения:

* ### Авторизация/регистрация:

Со стартовой страницы пользователь переходит на форму, где вводит логин и пароль.

* ### Личный кабинет:

Просмотр баланса, пополнение баланса.

* ### Работа с моделью:

На странице личного кабинета пользватель загружает отзывы и получает оценки по шкале 1-5 и confidence. 

* ### Просмотр истории предсказаний и транзакций:

Реализована возможность перейти на страницы с историей предсказаний и тарнзакций.

* ### Log Out:

Пользователь может разлогиниться.

* ### Запуск docker:

docker compose up
